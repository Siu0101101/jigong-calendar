# 记工日历

一个简单、清楚、适合手机使用的记工日历，用于记录每天工时并估算工资。

## 功能

- 按月查看日历和上班记录
- 支持一天记录多个工作时段
- 自动扣除时段之间的休息时间
- 支持跨夜班计算
- 按月、按周和自定义日期范围统计工时与预计收入
- 支持复制前一天或本周记录
- 支持导出 CSV 工时表和 JSON 完整备份
- 安卓版支持每月自动备份
- 数据保存在当前设备，不会自动上传服务器

## 使用方法

1. 在“设置”中填写每小时工价。
2. 点击日期，选择“上班”或“休息”。
3. 填写工作时段并保存。
4. 在“工资”页面查看统计结果。
5. 更换设备前先导出完整备份。

预计收入仅供记录和核对，实际工资请以最终结算为准。
